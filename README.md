# ZenTrack

ZenTrack is a calm, local-first time tracker for client and project work.

## macOS — coming soon

ZenTrack remains in private development. Public macOS installation is paused while release readiness, Developer ID signing, and notarization are completed.

There is currently no supported public installer, Homebrew tap, or in-app update channel. Historical release assets may remain in this repository, but they are not the current public launch path.

For current availability, visit [usezentrack.com](https://usezentrack.com).

## Repository purpose

This repository retains historical macOS release metadata and artifacts separately from the private application source. It must not contain source code, secrets, signing material, or build caches.
